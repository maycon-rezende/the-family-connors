# Hellsings — aplicativo mobile

Primeiro protótipo nativo do Centro de Comando Hellsings, criado com React Native, Expo e TypeScript.

## Como abrir no celular

1. Instale **Expo Go** no celular pela Play Store ou App Store.
2. Abra um terminal dentro da pasta `hellsings-app`.
3. No Windows PowerShell, execute `npm.cmd start`.
4. Espere o QR Code aparecer.
5. Android: abra o Expo Go e use **Scan QR code**. iPhone: leia o QR Code com a câmera.
6. O computador e o celular devem estar na mesma rede Wi-Fi.

## O que já existe

- abertura cinematográfica com a entrada do bunker;
- autenticação narrativa de nível Ômega;
- painel de comando mobile;
- indicadores de agentes, base e sucesso operacional;
- arquivos de missões desclassificáveis;
- Protocolo Vermelho interativo;
- navegação inferior preparada para os próximos módulos.

## Importante

Esta versão é uma experiência narrativa local. Não existe autenticação real, servidor, envio de contratos ou armazenamento de dados pessoais.
